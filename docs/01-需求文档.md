# 01 需求文档（产品需求）

## 1. 产品概述
一款 **Windows 图形界面软件**，批量把本地媒体文件（MP4/MP3 及常见音视频格式）通过语音识别 API 转成**与源文件同名**的 `.srt` 字幕文件。目标用户是完全不懂代码的人，最终交付**单个可双击运行的 exe**。

## 2. 已确认需求

| 编号 | 需求 | 说明 |
|---|---|---|
| R1 | 图形界面 | 简体中文 UI；拖拽/添加文件；文件列表；进度显示；开始/停止按钮 |
| R2 | 两种识别服务可切换 | ① 阿里云百炼 Paraformer；② 任意 OpenAI 兼容接口（填 Base URL + API Key + 模型名） |
| R3 | 识别语言中文为主 | 设置可选 zh / en / auto，默认 zh |
| R4 | 输入无硬性大小限制 | 文件量多、单个 ≤30 分钟 / ≤1GB；先拆音频再上传；超 API 单次上限时自动切块、偏移合并 |
| R5 | 输出位置统一 | 字幕统一输出到用户指定的文件夹，命名 `<源文件名>.srt` |
| R6 | 逐个排队转换 | 不做并发；单个失败跳过、记日志、继续下一个，结束弹汇总 |
| R7 | 配置本地保存 | API Key / 服务配置 / 输出目录存于 `%APPDATA%\Scrybe\config.json`，下次免填 |
| R8 | 交付单 exe | PyInstaller onefile + windowed，内置 ffmpeg；双击即用 |

## 3. 验收标准
1. 双击 exe 打开主窗口（不依赖本机 Python）。
2. 通过"添加文件"与拖拽都能加入 MP4/MP3；列表显示文件名/大小/状态。
3. 设置里可配置百炼或 OpenAI 兼容服务，语言默认为中文；配置被记住。
4. 点"开始转换"：文件逐个处理，界面不卡死；当前文件进度与总进度可见；可"停止"。
5. 处理成功的文件在输出目录生成同名 `.srt`，时间轴合理、中文正常（带 BOM，播放器可识别）。
6. 单个文件失败：状态标"失败"、日志有原因、队列继续，结束后弹"成功 N / 失败 M"汇总。
7. 中文文件名 / 带空格路径的源文件可正常处理。
8. 超过 OpenAI 单次上传上限的文件自动切块，合并后时间轴连续、无重叠丢失。

## 4. 非目标（本期不做）
- 字幕在线预览/编辑、翻译。
- 说话人分离、多语言混合精调。
- 登录/授权、付费/计费。
- API Key 的加密存储（本期明文存本机，DPAPI 加密列为后续增强）。
