# 开发需求

> 状态：已实现 · 维护人：项目作者 · 最后更新：2026-08-12

## 1. 项目背景

把视频、音频批量转成同名 `.srt` 字幕。普通用户（含小白）在 Windows 上使用：无需安装任何环境，绿色单文件 exe，双击即用，填入云端识别服务的 API Key 即可。识别由云端 API 完成，本机只负责提取音频、调用接口、生成字幕文件。

## 2. 目标用户

- 需要给本地视频/音频加字幕的非技术用户（中文为主）。
- 创作者、UP 主、课程制作者等批量场景。

## 3. 功能需求

### FR-1 文件导入
- 支持拖拽、按钮两种方式添加媒体文件，也支持整文件夹递归添加。
- 支持的扩展名：`.mp4 .mkv .mov .avi .wmv .flv .webm .mp3 .wav .m4a .flac .aac .ogg .m4v .mpg .mpeg`。
- 列表去重（按解析后的绝对路径）；重复添加自动忽略。

### FR-2 识别服务
- 二选一服务商：
  - **阿里云百炼**：Paraformer 实时模型（WebSocket 流式），中文识别效果好。
  - **OpenAI 兼容接口**：填写 Base URL / API Key / 模型名。
- 语言可选：中文 / English / 自动。

### FR-3 批量处理
- 文件逐个排队转换；单个失败自动跳过并记录，不影响后续文件。
- 结束后汇总显示"成功 N / 失败 M"。
- 失败项可一键**重试**，重试复用已缓存的音频、不重新提取。

### FR-4 并行提取音频
- 多个文件的音频提取**并行**进行，并发数可在设置中配置（1-8，默认 2）。
- API 识别**串行**进行，按队列顺序一个完成后再识别下一个。

### FR-5 输出与切块
- 字幕统一输出到指定目录（默认 `文档/字幕`），文件名为 `<源文件名>.srt`，UTF-8 with BOM 编码。
- 音频超过服务上限（OpenAI 约 25MB）时自动切块识别，块间按帧级精确偏移合并。
- 相邻句间隔小于「合并阈值」时合并为一条字幕。

### FR-6 进度与状态
- 列表实时显示每个文件状态：等待中 / 处理中 / 成功 / 失败 / 已取消。
- 底部显示队列进度（区分"提取"与"识别"两阶段）与单文件进度。
- 日志面板记录关键步骤与错误信息。

## 4. 非功能需求

- **离线可用 UI**：转码与切块全部本地完成，无外部二进制依赖（PyAV 内置 FFmpeg 解码库）。
- **健壮性**：单文件失败不中断队列；网络错误自动重试（OpenAI 兼容接口 429/5xx 指数退避）。
- **缓存复用**：提取后的音频缓存到临时目录，重试识别不重复提取。
- **安全**：API Key 只存本机 `%APPDATA%\Scrybe\config.json`，不进入仓库。
- **可维护性**：识别服务通过抽象基类接入，新增服务无需改动 UI 与管线。

## 5. 验收标准

1. 添加第二批文件后点击开始，已成功的第一批**不会被重复识别**。
2. 设置并行提取数为 N 时，音频提取阶段并发数不超过 N；识别阶段全程只并发 1 个。
3. 识别失败的文件，点击「重试失败」后直接从缓存音频开始识别，不重新转码。
4. 超过服务上限的音频自动切块，输出字幕时间轴连续、无重叠。
5. 打包后的 `dist/Scrybe.exe` 双击可运行，无需额外安装环境。
