# 执行步骤

> 版本：1.0 · 最后更新：2026-08-12

## 1. 环境准备

```powershell
# 创建虚拟环境（如已存在 .venv 可跳过）
python -m venv .venv

# 安装依赖
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

依赖清单见 [requirements.txt](../requirements.txt)：PySide6、requests、av（PyAV）、dashscope、pytest。

## 2. 日常开发流程

1. **跑基线测试**：`.venv\Scripts\python.exe -m pytest -q`，确认 18 项全过。
2. **修改代码**，遵守 [docs/设计规范.md](设计规范.md)。
3. **补测试**：改动逻辑需在 `tests/` 增加离线用例。
4. **跑测试**，全绿后再继续。
5. **手动冒烟**（可选，涉及 UI/编排改动时）：
   - 源码运行：`.venv\Scripts\python.exe -m app.main`
   - 真实 API：`python tools\live_dashscope.py <媒体文件> --api-key sk-xxx`
6. **更新文档**：改动涉及架构/配置/流程时，同步更新 [docs/](docs/) 对应文档。
7. **更新开发日志**：把今日完成与待办写入 `devlog/YYYY-MM-DD.md`（见 [CLAUDE.md](../CLAUDE.md)）。

## 3. 打包发布

```powershell
# 一键打包：装依赖 → 跑测试（不过则终止）→ PyInstaller
.\build.ps1
```

产物：`dist\Scrybe.exe`（单文件、无控制台，约 86~90MB）。

**发布前检查清单**：

- [ ] 测试全部通过
- [ ] exe 启动冒烟通过（启动数秒不崩溃，界面正常）
- [ ] 识别两类服务商至少各验证一次
- [ ] 大文件切块场景验证一次
- [ ] 失败重试场景验证一次
- [ ] `devlog/` 已记录本次发布内容

**发布流程**：

```powershell
# 提交代码
git add -A
git commit -m "..."

# 如有远端，推送
git push
```

## 5. 常见问题

- **测试不过**：先看是否改了依赖的接口（如 provider / pipeline 签名），再查具体断言。
- **打包后运行报缺少模块**：检查 `build.spec` 的 `hiddenimports` 是否覆盖动态导入（dashscope 用 `collect_all`）。
- **exe 被杀软拦截**：无数字签名所致，提示用户「更多信息 → 仍要运行」或在安全中心放行。
- **临时缓存占用**：缓存位于 `%TEMP%\Scrybe_cache`，关闭程序时自动清理；异常退出可用手动删除。
