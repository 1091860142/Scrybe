# 设计规范

> 版本：1.0 · 最后更新：2026-08-12

## 1. 编码规范（Python）

- 目标版本 **Python 3.12**；每个模块首行 `from __future__ import annotations`。
- 使用类型注解：函数参数/返回值、数据类字段（`dataclass`）均标注类型。
- 字符串/日志/异常消息使用**中文**，保持面向用户的信息可读。
- 模块、类、函数写 docstring（一句话说明职责）。
- 每行代码不超过约 100 字符；命名：模块/函数 `snake_case`、类 `PascalCase`、常量 `UPPER_SNAKE`。

## 2. 分层与依赖

- 依赖方向：`ui → core → providers`；**禁止** core/providers 层反向导入 ui 层。
- UI 层不直接处理耗时逻辑（转码/识别），统一交给 worker 线程。
- 数据模型集中在 `app/models.py`，不散落各层。

## 3. 错误处理

- **core 层**：业务失败抛 `PipelineError`（见 `app/core/pipeline.py`），worker 捕获后标 `FAILED` 并继续下一个文件。
- **provider 层**：抛带中文说明的 `RuntimeError`（如「未配置阿里云百炼 API Key」「百炼识别失败: …」）。
- **worker 层**：区分 `PipelineError`（业务失败）与其它异常（意外错误），均标 `FAILED` 并写日志。
- 网络请求（OpenAI 兼容）：429/5xx 指数退避重试 3 次（2s/4s/8s），退避期间检查停止标志。
- 临时资源（转码目录、切块目录）用 `try/finally` 清理，异常路径不残留。

## 4. 音频与时间规范

- 内部时间单位统一为**整数毫秒**；provider 在返回 `ProviderResult` 前完成单位换算。
- 转码统一为 **16kHz、单声道、s16 PCM WAV**，作为各服务共同输入。
- 切块偏移用**帧数**计算（`frames * 1000 // bytes_per_sec`），避免浮点累计误差。
- SRT 输出 **UTF-8 with BOM**（兼容记事本/播放器）；字幕文件编码一律如此。
- 合并阈值：相邻句间隔 `< merge_gap_ms` 时合并为多行字幕；过滤空白与过短（<50ms）句。

## 5. 线程与并发

- 队列在 worker 线程执行；**音频提取可并行**（并发数 = 配置 `parallel_extractions`，范围 1-8）。
- **API 识别必须串行**（保持队列顺序，一个返回后识别下一个），禁止并行调用识别接口。
- 停止信号用 `threading.Event`，在提取循环、识别循环、网络退避处检查。
- Signal 定义集中在 `QueueSignals`，参数类型固定，UI 侧按签名接收。

## 6. 测试规范

- 使用 pytest；测试文件位于 `tests/`，按被测模块命名（`test_<模块>.py`）。
- **离线优先**：不调真实 API。识别用 `FakeProvider`，转码用 monkeypatch 替换 `transcode_to_wav`。
- 需要验证「并行/串行」语义时，用带锁的计数器断言并发峰值。
- 测试不依赖网络、不依赖系统临时目录之外的路径。
- 真实链路验证使用 `tools/` 下的 `live_dashscope.py` / `live_openai.py` 手动执行。

## 7. 配置与安全

- 配置读写走 `app/config.py`，**禁止**在其它模块直接操作配置文件。
- API Key 只存 `%APPDATA%\Scrybe\config.json`；.gitignore 已排除 `config.json`。
- 配置文件原子写入（临时文件 + `os.replace`），损坏时回退默认值。

## 8. UI 规范

- 界面文案统一中文；状态显示使用固定枚举值（`FileStatus` 的 `value`）。
- 状态颜色：等待无色 / 处理中蓝 / 成功绿 / 失败红 / 已取消灰（见 `file_list_model.py`）。
- 进度条区分阶段：「提取」与「识别」两阶段显示不同文案。
- 耗时操作进行中禁用相关按钮（开始/重试/添加/设置），结束后恢复。

## 9. 版本与发布

- 打包流程见 [docs/执行步骤.md](执行步骤.md)：`build.ps1` 全流程，测试不过不打包。
- 发布前需通过启动冒烟（exe 启动数秒不崩溃）。
