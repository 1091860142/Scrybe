# 02 技术方案

## 1. 技术选型
| 项 | 选择 |
|---|---|
| 语言/框架 | Python 3.12 + PySide6（Qt6） |
| HTTP | requests |
| 中间音频 | 16kHz 单声道 WAV（PCM），约 1.875MB/分钟 |
| 音频提取/转码 | **PyAV**（内置 FFmpeg 解码库，pip 安装，无需外部二进制） |
| 切块 | 纯 Python（wave 模块，按帧数切） |
| 打包 | PyInstaller（--onefile --windowed） |
| 配置 | %APPDATA%\Scrybe\config.json |

> 说明：最初计划内置 ffmpeg.exe，因当前网络无法可靠下载二进制而改用 PyAV（同样基于 FFmpeg 解码库，功能等价，且减小 exe 体积、无需 GPL 再分发义务）。

## 3. 数据模型
- `Segment(start_ms, end_ms, text)`：两家 Provider 的时间统一换算为**整数毫秒**（百炼原生 ms；OpenAI 秒×1000 取整），SRT 生成与 Provider 无关。
- `ProviderResult(segments, language, raw)`。
- `FileJob(source, output_dir, status, error, progress)`；`FileStatus`：等待中/处理中/成功/失败/已取消。

## 4. 音频处理
- 统一转码：PyAV 打开媒体 → 选中音频流 → `AudioResampler(format="s16", layout="mono", rate=16000)` → 逐帧写入 `wave` 生成的 16k 单声道 WAV（解码错误转 `AudioError`，中文消息）。
- 切块条件由 `ProviderCapability.max_file_size_bytes` 决定：百炼=None（整文件）；OpenAI 兼容=24MB。
- 切块：纯 Python 用 `wave` 模块按 `rate*chunk_seconds` 帧数切块，逐块写新 WAV。
- 偏移合并：每块时长按帧数精确计算，`chunk_i.start = Σ 前 i 块时长`；识别结果加偏移后统一排序合并，时间轴连续。
- 临时文件放系统 temp 独立目录，finally 清理。

## 5. 两种 Provider 协议
### 5.1 OpenAI 兼容
- `POST {base}/v1/audio/transcriptions`，multipart：`file`、`model`、`language=zh`（auto 时省略）、`response_format=verbose_json`。
- 响应 `segments[]`：`start`/`end`（秒）/`text`。
- 429/5xx 重试：2s/4s/8s 退避、最多 3 次，重试间检查停止标志。

### 5.2 阿里云百炼 Paraformer（已实测确认）
- 采用官方 dashscope SDK 的 **`Recognition`（WebSocket 实时流式）**，`call(file)` 直接传本地 16k 单声道 WAV，无需 OSS/公网 URL。
- 模型 `paraformer-realtime-v2`，`format="wav"`，`sample_rate=16000`，`language_hints=["zh"]`。
- 结果：`result.get_sentence()` 返回句子列表，含 `begin_time`/`end_time`（**毫秒**）与 `text`。
- 实测：官方示例语音正确输出 `00:00:00,280 --> 00:00:03,820 Hello word, 这里是阿里巴巴语音实验室。`
- 依赖：`dashscope`（含 `websocket-client`）。Stop 在 websocket 调用期间不中断（当前文件完成后生效）。

## 6. Qt 线程模型
- 单个 `QThread` 托管 `QueueWorker`（moveToThread）；worker 持有阻塞调用，经 Signal 通信，绝不碰控件。
- 信号：`log` / `file_started` / `file_progress` / `file_done` / `queue_progress` / `queue_finished`。
- 停止：按钮 → `worker.stop()`（跨线程自动排队），在文件/请求之间生效。
- 失败处理：记日志 → 标失败 → 继续下一个 → 弹汇总（成功 N / 失败 M）。
- 主窗口：工具栏 + QTableView 文件表 + 当前进度条 + 总进度条 + 日志面板 + 拖拽。

## 7. 打包
- `build.spec`：onefile+windowed，`collect_all("av")` 收集 PyAV，excludes 未用 Qt 大模块（WebEngine/3D/Qml/Multimedia），`upx=False`。
- exe 预计 120~200MB；未签名 PyInstaller 可能被 Defender 误报，README 写明。
- 无 ffmpeg 外部二进制，无 GPL 再分发义务。
