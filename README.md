# Scrybe —— 批量视频/音频转字幕工具

把 MP4、MP3 等媒体文件批量转成**同名的 .srt 字幕文件**。运行在 Windows 上，绿色单文件，双击即用。

## 功能
- 图形界面：拖入文件或点按钮添加，列表显示文件名/大小/状态。
- 识别服务二选一：**阿里云百炼**（中文识别效果好）或 **OpenAI 兼容接口**（填 Base URL / API Key / 模型名）。
- 识别语言默认为中文，可改。
- 文件逐个排队转换，失败自动跳过并记录，结束后显示"成功 N / 失败 M"。
- 字幕统一输出到你指定的文件夹，命名为 `<源文件名>.srt`。
- 内置 ffmpeg：视频会自动先拆出音频再上传。

## 使用步骤
1. **准备一个识别服务的 API Key**（二选一）：
   - 阿里云百炼：打开百炼控制台（bailian.console.aliyun.com）→ 开通百炼 → 右上角头像/菜单里找到 **API-KEY** → 创建并复制（形如 `sk-xxxx`）。语音识别按用量计费，价格见官方文档。
   - 或其他支持 OpenAI 语音转文字接口的服务，把地址、Key、模型名填进去。
2. 打开 `Scrybe.exe`。
3. 点 **选择输出目录**，选一个字幕保存的文件夹。
4. 点 **添加文件**（或直接把文件拖进窗口），把要转的 MP4/MP3 加进来。
5. 点 **设置**，选择服务商、填入 API Key，语言保持"中文"，保存。
6. 点 **▶ 开始转换**，等待处理完成。
7. 打开输出目录查看 `.srt` 字幕，用播放器（PotPlayer / VLC 等）即可加载。

## 首次运行提示
- 程序没有数字签名，Windows Defender 可能会提示"未知发布者"：
  点 **更多信息 → 仍要运行** 即可。如被直接拦截，可在 Windows 安全中心 → 病毒和威胁防护 → 排除项里放行本软件。

## 常见问题
- **转换失败**：查看界面下方日志，常见原因：API Key 错误/欠费、网络不通、文件无法解码。
- **字幕时间轴不太准**：不同 API 返回的时间戳粒度不同，属正常现象。
- **文件很大**：超过 OpenAI 接口单次上传上限（约 25MB）时会自动切块识别再合并，无需你操作。
- **API Key 安全**：只保存在本机 `%APPDATA%\Scrybe\config.json`，请勿把 Key 告诉他人。

## 打包与开发（给开发者）
- 打包：运行 `build.ps1`，生成 `dist\Scrybe.exe`（内置 ffmpeg，exe 体积约 150~250MB）。
- 文档：见 `docs/`（需求/技术方案/设计规范/执行步骤），开发日志见 `devlog/`。
