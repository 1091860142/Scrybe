# 开发日志

每天一个文件：`devlog/YYYY-MM-DD.md`，记录当天完成的开发事项和待办事项。

## 日志模板

```markdown
# 开发日志 YYYY-MM-DD

## 今日完成
- [功能/修复/重构] 描述（涉及文件、验证方式）

## 待办事项
- [ ] 描述
```

## 维护规则

- 每次开发任务完成后，由 Claude Code 自动更新当日日志（见项目根 [CLAUDE.md](../CLAUDE.md) 的「开发日志维护」）。
- 当天若已有日志文件，**追加**到对应小节，不要覆盖已有内容。
- 记录要点：功能/修复/重构内容、涉及的关键文件、验证方式（测试/打包）、遗留的待办。
